## Super Mario Galaxy 1 & 2 Save File Region Converter v1.1.1

A simple Windows tool for converting Super Mario Galaxy 1 and Super Mario Galaxy 2 Wii save files between regions.

### Features

* Supports Super Mario Galaxy 1 and Super Mario Galaxy 2
* Convert save files between supported regions
* Preserves your existing game progress
* Rebuilds the Wii `data.bin` save container
* Creates an SD-ready output file
* Simple Windows GUI
* Custom output location
* No donor save file required for supported conversions

### Supported regions

**Super Mario Galaxy**

* NTSC-U / USA
* PAL / Europe
* NTSC-J / Japan
* Korea

**Super Mario Galaxy 2**

* NTSC-U / USA
* PAL / Europe
* NTSC-J / Japan
* Korea
* Hong Kong / Taiwan

### Usage

1. Open `GalaxySaveRegionConverter.exe`
2. Select Super Mario Galaxy 1 or Super Mario Galaxy 2
3. Select your source `data.bin`
4. Choose the target region
5. Choose where you want to save the converted file
6. Click **Analyze**
7. Click **Convert**
8. Extract the generated ZIP to the root of your Wii SD card
9. Import the save through the Wii Data Management menu

Always make a backup of your original save before converting.
